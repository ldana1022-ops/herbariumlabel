# نظام إدارة ملصقات عينات المعشبة النباتية

نظام مؤسسي لإدخال بيانات العينات النباتية، حفظها في قاعدة بيانات حقيقية، ثم توليد وطباعة Herbarium Label مطابق للقالب الرسمي المرفق.

## الصفحات

1. **لوحة التحكم (/)** — إحصائيات: إجمالي العينات، مصنفة، غير مصنفة، مضافة حديثًا (آخر 30 يومًا)، توزيع حسب المنطقة وحسب العائلة. اختصارات: إضافة عينة، قاعدة البيانات، البحث، طباعة الليبلات، تصدير Excel.
2. **إضافة عينة (/specimens/new)** — نموذج بجميع الحقول الخمسة عشر، حقول التصنيف اختيارية. بعد الحفظ: رسالة نجاح + معاينة الليبل مباشرة في نفس الصفحة مع زر طباعة (بدون تنقل بين صفحات).
3. **قاعدة البيانات (/specimens)** — جدول شبيه بـ Excel بكل الأعمدة + Status + Actions (عرض/تعديل/طباعة/حذف مع تأكيد)، بحث نصي وتصفية حسب العائلة والمنطقة والجامع والتاريخ وحالة التصنيف، تحديد متعدد للطباعة الجماعية، وزر Export to Excel.
4. **تفاصيل العينة (/specimens/$id)** — عرض كامل + بطاقة Determination مستقلة لإضافة/تعديل التصنيف لاحقًا + معاينة الليبل + طباعة.
5. **تعديل العينة (/specimens/$id/edit)**.
6. **الطباعة (/print)** — صفحة طباعة نظيفة تعرض ليبل واحد أو عدة ليبلات على ورق A4 بمقاس ثابت، بدون أي عناصر واجهة.

## قالب الليبل

مطابق للمرجع: إطار مزدوج، رأس رمادي فاتح بسطرين (FLORA OF SAUDI ARABIA KINGDOM / HERBARIUM OF NATIONAL CENTER...)، ثم الحقول بخط Serif بالترتيب: Scientific Name (النوع مائل)، Family، Local Name، Locality، Region، Lat (N) / Long (E) / Alt في سطر واحد، Collection Date، Collector(s)، Det.، Determined By، Determination Date، Notes. العناوين ثابتة غير قابلة للتعديل؛ الحقول الفارغة تظهر كخط منقّط للتعبئة اليدوية. مقاس ثابت 105×74 مم (4 ليبلات في صفحة A4).

## اللغة والهوية

واجهة عربية RTL افتراضيًا مع مبدّل إلى الإنجليزية (LTR)، والليبل يبقى إنجليزيًا علميًا دائمًا. لوحة ألوان: أبيض ورمادي وأسود مع أخضر مؤسسي هادئ، خط Serif للِّيبل وخط عربي واضح للواجهة، بلا زخرفة تجارية.

## التفاصيل التقنية

- **Lovable Cloud** لقاعدة البيانات. جدول `herbarium_specimens`: `id uuid PK`, `accession_number text UNIQUE NOT NULL`, `scientific_name`, `family`, `local_name`, `locality`, `region`, `latitude numeric`, `longitude numeric`, `altitude_m numeric`, `collection_date date`, `collectors`, `determination`, `determined_by`, `determination_date`, `notes`, `created_at`, `updated_at` (trigger للتحديث). حالة التصنيف محسوبة من وجود `determination`. الوصول للنسخة الأولى عام (قراءة/كتابة) مع GRANTs صريحة، والبنية جاهزة لإضافة `user_id`, `image_url`, `qr_code`, سجل تعديلات، وصلاحيات لاحقًا دون تغيير الحقول الحالية.
- CRUD عبر `createServerFn` + TanStack Query (invalidate بعد كل تعديل).
- التحقق بـ Zod على العميل والخادم: تفرّد Accession Number، نطاق الإحداثيات، صحة التاريخ، الحقول الإلزامية (Accession, Scientific Name, Family, Locality, Collection Date, Collector).
- تصدير Excel عبر `xlsx` بجميع الحقول + Status، صف لكل عينة.
- الطباعة عبر `@media print` + `@page` بمقاس ثابت، دون مكتبات إضافية.
- بيانات تجريبية: 8 عينات (منها الليبل المرجعي) تُضاف ضمن الترحيل، قابلة للحذف من الواجهة.

## خارج النطاق الآن

رفع الصور، QR/Barcode، الخرائط، سجل التعديلات، وحسابات المستخدمين — البنية تسمح بإضافتها لاحقًا.
